- `@Composable fun PampaAccountRow(onDownloadStore: () -> Unit, modifier: Modifier = Modifier, labels: PampaAccountLabels = PampaAccountLabels())` — La riga già collegata a [PampaAccount]: legge lo stato, lo rilegge quando la riga compare, e al tocco apre lo Store sulla pagina giusta. Senza Store chiama [onDownloadStore] (l'indirizzo della pagina di rilascio lo sa l'app, R8).

- `fun wordsChangedText(name: String, byThem: Boolean, labels: PeopleLabels = PeopleLabels()): String` — L'avviso delle parole cambiate: [byThem] se ha rinnovato l'altro, altrimenti ho rinnovato io.
- `@Composable fun FluidPeopleRow(entries: List<PeopleRowEntry>, onPick: (PeopleRowEntry) -> Unit, modifier: Modifier = Modifier, onMore: (() -> Unit)? = null, labels: PeopleLabels = PeopleLabels())` — La fila delle persone per il foglio di condivisione (`FluidShareSheet(people = …)`): «I tuoi dispositivi», poi le persone e i gruppi recenti, coi loro avatar, e «Altri…». Gli id sono quelli dello Store, validi solo per quest'app: chi li riceve li ripassa a `PampaPeople.send`. Senza voci non disegna niente (P1).
- `@Composable fun rememberPampaPeopleRow(): List<PeopleRowEntry>` — La fila letta da Pampa Store (`PampaPeople.row`); vuota finché non risponde, e senza Store.
- `@Composable fun FluidSharedWithYou(items: List<SharedItem>, onOpen: (SharedItem) -> Unit, modifier: Modifier = Modifier, now: Long = System.currentTimeMillis(), onAttribution: ((SharedItem, AttributionAction) -> Unit)? = null, labels: PeopleLabels = PeopleLabels())` — «Condivisi con te» (`progetto.md` § 3.7; scelta D8): la stessa sezione in ogni app, con l'avatar, «Da Alessio · ieri» e il titolo. **Se è vuota non compare**: niente sezioni vuote che chiedono attenzione.
- `@Composable fun FluidAttribution(from: PeopleRowEntry, onAction: (AttributionAction) -> Unit, modifier: Modifier = Modifier, labels: PeopleLabels = PeopleLabels())` — «Da Alessio» (`FluidAttribution`, come `SWAttributionView` di Apple): resta sulla cosa anche dopo che l'hai aperta o importata. Un tocco apre le quattro voci: Rispondi, Apri la conversazione, Togli dai condivisi, Non mostrare più da Alessio in questa app.
- `@Composable fun FluidQuickReply(visible: Boolean, to: String, quoted: String, onSend: (String) -> Unit, onDismissRequest: () -> Unit, labels: PeopleLabels = PeopleLabels())` — «Rispondi» (`FluidQuickReply`): un foglio piccolo con la cosa citata sopra. La risposta va nella conversazione in Pampa Mail, o resta attaccata alla cosa (`PampaPeople.reply`).
- `@Composable fun FluidWordsChangedNotice(name: String, byThem: Boolean, onCompare: () -> Unit, onDismiss: () -> Unit, modifier: Modifier = Modifier, labels: PeopleLabels = PeopleLabels())` — L'avviso delle quattro parole cambiate (come il numero di sicurezza di Signal): «Le parole con Marco sono cambiate perché Marco ha rinnovato le chiavi». Non è un allarme: le chiavi nuove sono firmate dalla stessa radice. La verifica a distanza è da rifare per tenere il segno «verificato» (`PeoplePolicy.RENEWAL_DROPS_WORDS_VERIFICATION`).
