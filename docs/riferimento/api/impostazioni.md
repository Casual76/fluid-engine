  - `data object Checking : FluidUpdateUiState` — Si sta chiedendo al manifest.
  - `data object UpToDate : FluidUpdateUiState` — Si e' controllato e non c'e' niente di piu' nuovo.
  - `data class CheckFailed(val message: String? = null) : FluidUpdateUiState` — Il controllo non e' riuscito (rete, manifest). [message] e' il testo tecnico, se c'e'.
  - `data class Available(val release: FluidUpdateRelease) : FluidUpdateUiState` — C'e' una versione nuova e non si e' ancora toccato niente.
  - `data class Downloading(val release: FluidUpdateRelease, val progress: Float?, val downloadedBytes: Long = 0L, val totalBytes: Long = 0L) : FluidUpdateUiState` — Si sta scaricando. [progress] e' 0..1, o **null se il peso non si conosce** (allora la barra e' senza fine: "0%" per tutto il download e' peggio di non dire niente).

  - `data class Installed(val release: FluidUpdateRelease) : FluidUpdateUiState` — Installata. L'app, di norma, sta per essere sostituita.
  - `data class Failed(val release: FluidUpdateRelease, val message: String) : FluidUpdateUiState` — L'installazione si e' fermata ([message]: quello che il sistema ha detto). Si puo' riprovare.
  - `data class NeedsPermission(val release: FluidUpdateRelease) : FluidUpdateUiState` — Serve il permesso di installare da questa app: Android lo chiede una volta, e conviene dirlo prima.

- `val FluidUpdateUiState.isBusy: Boolean` — Vero se c'e' qualcosa in corso che un secondo tocco non deve rilanciare: un controllo, un download, la verifica, l'installazione — e anche l'attesa della conferma ([FluidUpdateStage.AwaitingUser]), perche' finche' il sistema non ha avuto risposta ripartire vorrebbe dire due finestre di conferma.
- `val FluidUpdateUiState.canInstall: Boolean` — Vero se il tasto principale e' "installa": c'e' una versione che si puo' (ri)avviare.
- `fun AvailableAppUpdate.toFluidUpdateRelease(): FluidUpdateRelease` — La versione che `AppUpdater.check` ha trovato, nei termini della vista.
- `fun AppUpdateInstallState.toFluidUpdateState(release: FluidUpdateRelease): FluidUpdateUiState` — Un passo di `AppUpdater.install` come stato della vista, per la versione [release] che si sta installando.
